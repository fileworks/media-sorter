# Bundled third-party data

MediaSorter ships two small data sets so that location tags work offline.
Neither is used to contact any service; both are read locally.

## Place names — GeoNames

Location tags name the nearest populated place from the GeoNames
`cities1000` export (places with at least 1,000 inhabitants).

- Source: GeoNames, https://www.geonames.org/
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0),
  https://creativecommons.org/licenses/by/4.0/
- Changes: reduced to latitude, longitude, place name and country code, with
  coordinates rounded to four decimal places.

The data is provided "as is" without warranty. Place names and positions may be
incomplete or out of date.
