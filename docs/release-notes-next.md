# Next release

## Navigation

MediaSorter now uses one three-stage workflow: **Sources → Review → Execute**.
The previous Configure/Analyze/Preview/Sort/Report wizard has been removed.
Review keeps organization, exact duplicates, similar media, bursts,
destination reconciliation, validation, and issues together, while running and
completed operations remain visible in the persistent operation center.

Returning to an earlier stage explains which scan or reviewed plan becomes
stale before it is discarded. Execute remains unavailable until the current
folders have been scanned and the current plan has been reviewed.
